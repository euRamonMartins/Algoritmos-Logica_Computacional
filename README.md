# 🧠 Algoritmo e Pensamento Computacional

Este repositório contém exercícios e programas desenvolvidos durante os estudos da disciplina de **Algoritmo e Pensamento Computacional**.

O objetivo deste repositório é registrar minha evolução no aprendizado da **lógica de programação**, do **pensamento computacional** e do desenvolvimento de algoritmos utilizando a linguagem **C**.

## ▶️ Como executar os programas

### 1. Clone o repositório

```bash
git clone <url-do-repositorio>
```

### 2. Acesse a pasta do projeto

```bash
cd Algoritmo-e-Pensamento-Computacional
```

### 3. Compile um arquivo C

```bash
gcc nome_do_arquivo.c -o programa
```

### 4. Execute o programa

No Windows:

```bash
programa.exe
```

No Linux:

```bash
./programa
```
